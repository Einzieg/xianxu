# 弦序 v0.1.4 · 曲间停顿与 DD 初始化防护

## 更新

- 自动连播在上一首结束、按键释放后等待 3 秒再开始下一首，适用于顺序、随机、列表循环和单曲循环。
- 等待期间支持暂停、继续和停止；手动切歌不额外增加 3 秒等待。
- DD 首次加载和初始化期间临时拦截左右 Win 键，防止初始化副作用弹出开始菜单；完成或失败后移除拦截，正常播放不拦截 Win 键。
- 保留已有曲库和设置，不自动重编曲谱。

## 安装与验证范围

Python 回归测试 200 项（196 项通过、4 项跳过），前端测试 20 项通过；打包引擎通过独立数据目录下的启动、状态读取及关闭检查，全程不触发真实按键。

Windows 10/11 x64，安装包包含 Python 引擎、模型和 DD 组件。升级前请保存内容、停止演奏并正常退出旧播放器。

DD 防护已做模拟后端回归验证，尚未验证真实首次初始化场景。未完成干净 Windows 虚拟机安装、升级和卸载验收；本次继续作为预览版发布。应用安装包未签名，可能出现 SmartScreen 提示。
