# v0.1.3 · 旋律走向优先

- 新导入的单旋律谱、音频识别旋律优先保留上行、下行及高音峰值，减少八度折叠导致的高低反转。
- 同音重复保留相同目标音；九键音域不足时压缩旋律，长音阶仍可能出现平台，并非无损还原。
- 稀疏伴奏在修正后的主旋律下重建；真正的多声部和弦继续使用原有策略，不强制删成单旋律。
- 升级不自动重编或清空已有曲库。整库重编可使用仓库中的 `music_contour.py` 生成候选后试听。
- 安装包继续包含 DD 组件；已有驱动按原安装逻辑复用，不随软件卸载移除共享驱动。

个人曲库、下载曲谱与音频不包含在安装包中。安装前请保存曲谱、停止演奏并正常退出旧播放器。

验证：Python 194 项测试中 190 项通过、4 项跳过；前端 20 项通过。脱离源码目录的独立引擎已通过 MIDI 高音峰值、回落、同音重复以及 ONNX 合成音频转谱验证，全程未发送真实按键。
