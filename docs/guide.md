# 弦序使用指南

面向《洛克王国：世界》9键乐器的 Windows 桌面播放器。新版使用 **Tauri 2 + React + TypeScript**，常驻 Python 引擎负责转谱、谱库、播放队列和 DD/Win32 输入。独立“乐器适配”页已从新版移除：导入/转谱时自动生成9键谱，原始识别谱保留供对照。

## 启动和构建

已构建后，在项目目录的 PowerShell 7 中运行：

```powershell
$ErrorActionPreference = 'Stop'
.\Start-MusicPlayer.ps1
```

首次构建需要 Python 3.12+、Node.js、Rust MSVC 工具链、Visual Studio C++ Build Tools 和 WebView2 Runtime：

```powershell
$ErrorActionPreference = 'Stop'
uv sync
if ($LASTEXITCODE -ne 0) { throw 'Python dependency installation failed' }
.\Build-TauriPlayer.ps1
.\Start-MusicPlayer.ps1
```

`Build-TauriPlayer.ps1` 生成工作区版，依赖项目 `.venv/Scripts/python.exe` 和 `music_service.py`。`Build-Installer.ps1` 另生成包含 Python 引擎和模型的独立 NSIS 安装包。安装包版优先运行相邻 `engine/rock-music-engine.exe`；`ROCK_MUSIC_HOME` 可显式覆盖根目录。只有显式打包 DD 的安装器才会在安装阶段调用驱动安装程序；应用启动不会自动安装驱动，也不会自动演奏。详见 [安装包构建](packaging.md)。

旧版 `music_player.py` 和连点器 `main.py` 保留用于回退，不是新版入口。不要同时运行旧版演奏器与新版，以免全局快捷键或 DD 后端竞争；新版自身会防止重复启动。

## 谱库与播放队列

- 导入 TXT 简谱、MID/MIDI，或在音频转谱页选择本地音频；谱子会保存到本地谱库。
- 原谱与9键编配结果分别保存。音符预览可以对照原始音高，适配统计不等于识别准确率。
- **顺序播放**：按列表逐曲播放，末尾停止。
- **随机播放**：打乱候选列表，遍历其他曲目后重新洗牌，避免多曲时立即重复上一曲。
- **列表循环**：末尾回到第一曲。
- **单曲循环**：自然结束后重复当前曲；手动下一首仍会切换曲目。
- 支持搜索、选择、上一首/下一首、暂停/继续、停止、删除和导出 MIDI。
- 每首曲目右侧都有“删除”按钮，详情底部也可“删除曲谱”。确认后仅移除谱库记录，不删除原始音频、TXT 或 MIDI 文件；取消不作更改。演奏（含暂停）、转谱或校准期间须先停止/结束任务。删除失败会保留原记录，删除最后一首后显示空谱库。
- 播放模式、选择曲目、设置和谱库跨重启保存；重启不会自动恢复发键。

仅曲目**正常结束**后才切下一首。停止、按键失败、窗口关闭不会自动跳过继续发键；失焦会暂停并释放本轮按键。F10 停止会同时终止后续队列和取消转谱/校准任务。

谱库位于 Tauri 的 Windows 应用数据目录 `%APPDATA%/com.rockmusic.workspace-player/library.json`，引擎日志为同目录 `engine.log`。采用临时文件替换保存；读取失败会报错，不会用空列表覆盖损坏文件。备份该目录即可保留谱库。原 MP3 不复制进谱库，已保存的音符不依赖其源路径。

## 第一次演奏

1. 正常关闭旧版演奏器，在游戏里打开对应乐器界面。
2. 在设置中“捕获游戏窗口”，3秒内切到游戏。
3. 导入或转换歌曲，先使用**无按键预览**检查时间轴、键位和队列。它不发声，也不操作游戏。
4. 选择 DD 或 Win32 输入，点击播放/继续会尝试切回已捕获的游戏窗口；切换失败不会发送按键。默认播放时缩为当前屏幕左上角置顶小窗，点击“展开谱库”恢复原来的大小和位置；可关闭自动小窗。
5. **F8** 开始当前曲，**F9** 暂停/继续，**F10** 停止并释放按键。预览开关同步到引擎，F8 和播放按钮使用相同的真实/无按键预览模式。

快捷键优先使用 Windows Raw Input 后台监听，不依赖普通键盘钩子的传递顺序；注册失败会记录日志并回退到按键状态轮询。仅处理 F8/F9/F10，不拦截游戏自身按键。日志记录监听启动、快捷键动作和执行结果，不记录其他按键。游戏环境中的可用性仍需实测；若快捷键无效，可点击置顶小窗的停止按钮，切出游戏也会触发失焦暂停。

DD 实例在引擎生命周期内复用，连续演奏不会反复初始化 DLL。关闭 Tauri 时先请求引擎停止、取消任务并释放按键，确认正常退出后关闭窗口；释放失败会提示重试，而不是强制杀进程。父进程异常退出或管道断开时，引擎也会尝试停止。

**DD 是全局输入，不支持对后台窗口独立投递。** 失焦保护不能让 Windows 的焦点判断与发键成为原子操作。请在游戏演奏时保留前台焦点；驱动无响应或强制终止进程不能保证释放成功。

## 转谱识别与自动9键编配

支持本地 MP3、WAV、FLAC、OGG，0.1～300秒。

- **乐器音符模型（默认）**：使用 Spotify Basic Pitch 的本地 ONNX 模型识别音符，再从多声部候选中跟踪主旋律。支持自动、偏高、偏中、偏低音区选择；这不是指定乐器的音源分离。
- **旧版频谱（对照）**：保留离线频谱谐波分析和时序跟踪，方便和升级前的结果对比。
- **独奏单音**：保留 YIN 检测，适合清晰独奏或哼唱；乐器实测校准仍使用稳定单音测量，不混用主旋律估计。
- 默认「主旋律」：识别结束后自动移调、折叠八度、替代缺失音并简化过密/伴奏音，输出当前9键可弹的单旋律；无需另开适配页面或再次应用。
- 可选「保留和弦（实验）」：在乐器音符模型下选择，保留全部 v2.1 主旋律音符，并补充通过起音校验及较严格持续证据筛选的和弦音；标记 `chords-v1`。主奏音区偏好仅影响主旋律，不推测额外和声，也可能混入伴奏或泛音，需先试听校对。默认 `legato-v2.1` 主旋律结果不变。
- 游戏的9键限制的是可用音高，不是只能按一个键。和弦适配对相近起音（40ms内，不移动起点）联合分配不同键位；保留各音起点与独立时值，仅在同键再触发时截断前音尾部。同刻同音合并，超过可用键数的同组音符会删减并计入摘要。谱库保存声部模式，修改键位后重新适配仍保留该模式。
- 适配保留所选音符起点、休止空隙和总时长，不把删除音符后的时间轴压缩。
- 修改9键映射后，已有谱子在查看/播放时从保存的原谱重新编配，避免在已适配结果上反复移调。

Basic Pitch 是**音符识别模型，不是音源分离模型**。检测到多声部不等于知道用户想听哪条主旋律；合奏、和弦、同音色伴奏仍可能误选声部。偏高/中/低音区是选声部的约束，不是完整乐器分离。9键也无法完整还原任意原曲。真实歌曲的音符数量、可弹率或合成测试不能代替听感/原谱校对，不宣称仅接入模型就已经达到人工扒谱准确度。

模型位于 `models/basic-pitch/nmp.onnx`，下载来源、版本与校验信息见同目录 `SOURCES.json`，许可见 `LICENSE`。使用 CPU ONNX Runtime，本地推理，不安装 TensorFlow/PyTorch，不会将音乐上传。模型缺失或损坏会报错，不静默回退到旧版频谱。

**已有谱子不会自动重新识别。** 升级后请重新选择原音频，用“乐器音符模型”转谱；结果另存为一条新记录，旧谱不会被覆盖。谱子详情显示已记录的引擎和主奏音区。

**重奏补全 v2.1** 保留经试听确认的 v2 主声部方案：结合原音频局部起音证据抑制长音误拆，并按尾音衰减跟踪后续旋律。修正了短重奏被筛选丢弃后出现人工空隙的问题：仅恢复与前音精确衔接、具有起音及正向持续证据、并延伸到下一已选音的同音片段；不合并原有重奏、不凭空填充休止。九键适配也不会把连续同音分配成不同按键。新转谱标记为 `legato-v2.1`，旧曲谱不自动覆盖，需要重新转谱。长混响和弱起音仍可能导致漏音或多余音，不能保证无误。

### 分段试听，分清识别误差和9键改编

谱库中的“分段试听”可选择起点及最长30秒片段，对比：

1. **原曲**：读取本地音频同一时间段；原文件移走后此项不可用，TXT/MIDI 导入不提供原曲。
2. **识别旋律**：用统一合成音色播放未适配的识别音符。
3. **9键版本**：用同一种合成音色播放适配结果；不是游戏音色或游戏实录。

若第2项已有杂调，问题在音符识别/主声部选择；若第2项接近原旋律而第3项变化大，则主要是九键音域和缺失音限制。试听不会发送按键，不自动出声；点击音频控件播放。切换曲目、开始演奏/校准/后台任务以及停止按钮/F10会停止试听，避免与游戏声音混在一起。

转谱在后台线程进行，支持进度、取消；取消不会写入半成品。用户音频不上传网络。新转谱结果不会覆盖旧版导出的 MIDI。

## 实测键位与校准

默认提供以下九键映射；工作区如存在个人 `music_settings.json` 则读取其中设置。该个人文件不随源码发布：

| 按键 | B | F | G | H | J | K | T | Y | U |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 音高 | A2 | E3 | F3 | G3 | A3 | B3 | C4 | D4 | E4 |
| MIDI | 45 | 52 | 53 | 55 | 57 | 59 | 60 | 62 | 64 |

设置中可以修改键位/音高，也可以重新实测：关闭背景音乐与其他播放声音，保留乐器音效，捕获游戏后显式启动校准。**校准会真实发送9个测试按键并录制默认系统输出的回环声音**；失焦、不稳定、取消均会中止，不用默认值冒充测量结果。私人校准录音不随仓库发布。

## 文本简谱

当前 `1=C3`，每个数字默认一拍，BPM 默认120。音符用空格分隔：

```text
// 小星星片段
5 5 2' 2' 3' 3' 2':2 |
1' 1' 7 7 6 6 5:2
```

`'` 高八度、`,` 低八度；`#4`/`b7` 升降音；`0` 休止；`-` 延长上一音；`:2` 两拍；`:1/2` 半拍；`[3 5 7]` 和弦。新导入的 TXT/MIDI 保留多声部，自动做和弦九键适配，不再强制抽成单旋律；旧谱不自动覆盖，需重新导入。BPM 影响文本解析，速度倍率影响播放；按键保持10～150ms，是短脉冲而非跟随音长持续按住。同刻的不同键会连续发送按下事件、共同保持后分别释放，不是操作系统级原子同时按下。

## 验证

```powershell
$ErrorActionPreference = 'Stop'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
if ($LASTEXITCODE -ne 0) { throw 'Python tests failed' }
.\Build-TauriPlayer.ps1
```

测试覆盖谱库持久化、四种模式、停止不续播、失焦/异常不切曲、DD 后端复用、转谱自动适配/取消、JSON-lines 通信，以及合成带低音伴奏旋律、重复音、静音等识别场景。自动化测试使用模拟输入或无按键预览，不向游戏发送按键。
